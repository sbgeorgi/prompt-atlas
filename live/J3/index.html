01

Approach

Every page is a set of decisions about order. We make fewer of them, and make them visible.

We begin with the material: the words, the numbers, the people who will read them. A grid is not decoration laid over content; it is the agreement that lets one hundred pages, four languages and three printers behave like a single document.

Our systems use one typeface, a short list of sizes and a strict set of rules. That restraint is what makes a hospital corridor, an annual report and a mobile app recognisably the same voice.

05

Questions

Do you work with existing typefaces?

Yes. Most systems use a licensed grotesque or an open-source family. We only draw letters when the project needs a character no existing face supplies.

How large are the teams you work with?

From a single editor to a communications department of sixty. We write the manual for the smallest team that will have to maintain it.

Can you deliver the system in code?

We supply CSS tokens, layout components and a reference page. Your developers keep their stack; we keep the type honest.

What do you need from us to begin?

Ten representative documents, a list of languages, and one person with the authority to say yes.
