Questions, answered plainly.

01Does Halden need access to our source code?

No. It reads commit metadata, build results and deploy events. Source files stay where they are.

02Can we run it on our own infrastructure?

Yes. The same release ships as a hosted service or as a container you operate yourself.

03How long does setup take?

Install the CLI, sign in, and connect one repository. The timeline fills in from your existing history.
